# Orbit

### A Student's Personal Manager

Orbit is an all-in-one productivity app built for students who want to manage their academic and personal life from a single place.

Instead of juggling multiple apps for planning, reminders, habit tracking, coding practice, and budgeting, Orbit brings everything together in one clean, offline-first experience.

## Highlights

* Unified task, event, habit, coding, and budget management
* Offline-first design with local data storage
* Smart recurring schedules for events and habits
* Progress tracking with visual analytics and charts
* Coding Problem of the Day and contest tracking
* Configurable reminder notifications
* Dark, Light, and System display modes
* Modern, production-grade Android UI
* Fast, lightweight, and privacy-friendly

## Minimum Requirements

* Android 10 (API 29) or higher

## Installation

### Option 1: Download APK

Download the latest APK from the GitHub Releases page and install it on your Android device.

### Option 2: Build from Source

```bash
git clone https://github.com/<username>/orbit.git
```

Open the project in Android Studio and build:

```bash
./gradlew assembleRelease
```

The generated APK can then be installed on any supported Android device.

## Privacy

Orbit respects user privacy.

* No accounts
* No cloud storage
* No analytics
* No user tracking
* No personal data collection

All user data remains on the device and is never transmitted to external servers.
